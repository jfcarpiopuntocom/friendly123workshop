01Alcance y regla

Este documento describe la suite de mantenimiento construida sobre friendly-123 el 30 de agosto de 2026, a partir del inventario de APIs gratuitas aprobado para las tres apps de la línea y para sus sitios de marketing. El trabajo cubre telemetría técnica opt-in, distribución de versiones, salud de landings, higiene del mantenedor y correo transaccional de contacto. No cubre almacenamiento en la nube de inventario, ventas, clientes, pacientes, copias de seguridad, PINs ni códigos de licencia.

La regla operativa es una sola: de la libreta no sale más que un JSON con campos de lista blanca. Los campos admitidos son aplicación, versión, shell, módulo, mensaje, agente de usuario, estado de red, idioma, origen, tipo de evento y marca de tiempo. Cualquier cadena que parezca licencia, SKU, cliente, venta, PIN o correo se sustituye por una marca de redacción antes de guardarse o enviarse. El Worker de licencias vuelve a aplicar el mismo filtro en el servidor.

El canal de actualización de la aplicación sigue siendo version.json. GitHub Releases no se consulta desde el cliente. jsDelivr no se usa. Google Analytics, Tag Manager y QuickChart no se instalan dentro de la SPA.

02Entregables por fase

Fase 0 — Contrato de privacidad

Módulo mantenedor-privacidad.js. Opt-in apagado de fábrica, guardado en f123_mantenedor_optin. Una prueba con el mensaje «stock of SKU ABC and cliente Ana PIN 555 F123-AAAA-BBBB» produjo «[redacted] of [redacted] ABC and [redacted] Ana PIN [redacted-pin] [redacted-license]». El nombre de producto friendly-123 no se altera.

Fase 1 — Disponibilidad y formularios públicos

El inbox del mantenedor comprueba que el origen responde. En producción esa misma URL es el monitor de UptimeRobot (capa gratuita, hasta cincuenta monitores). La página de contacto incluye un control de Turnstile de laboratorio; el Worker verifica el token real cuando existe TURNSTILE_SECRET. No se usa reCAPTCHA.

Fase 2 — Reporte de problemas

En Avanzado aparece la tarjeta «Technical reports (opt-in)». El dueño puede permitir reportes técnicos, pulsar «Report a problem», escribir módulo y descripción, y ver el JSON sanitizado antes de confirmar el envío. Con el permiso encendido, los errores no capturados y las promesas rechazadas pueden enviarse como reporte técnico. El destino es un Issue de GitHub y, en paralelo, una fila de Google Sheet, ambos detrás del Worker. En el laboratorio el ticket se guarda en el inbox local f123_mantenedor_lab.

La encuesta corta «qué te trabó esta semana» vive solo en la landing. No hay instrumentación dentro de Sold, Sync ni la puerta de PIN.

Fase 3 — Versiones

La aplicación consulta version.json, ahora en 1.7.41 con shell f123-shell-v154. El script scripts/release-github.sh crea la etiqueta de GitHub al bumpear, como higiene de repositorio. El cliente no llama a api.github.com.

Fase 4 — Landings

PageSpeed Insights opera en modo aviso sobre landings, umbral 80, sin fallar el build. El script es scripts/pagespeed-gate.js. Search Console queda descrito en el inbox como alerta de indexables y 404; la property de GitHub Pages todavía no está atada.

Fase 5 — Higiene del mantenedor

Have I Been Pwned se consulta con scripts/hibp-check.js contra correos de administración, nunca contra correos de clientes. VirusTotal no se cableó: no hay APK ni zip de distribución fuera de tienda en este entregable.

Fase 6 — Correo y vetos

El Worker acepta RESEND_KEY, MAIL_FROM y MAIL_TO para confirmar contactos desde dominio propio. Google Fonts, Unsplash, Pexels, GA4, GTM y QuickChart no entran a la SPA. Las landings de marketing que ya cargaban tipografía de Google no se reabrieron en este pase.

05Pendiente de secretos

El laboratorio recorre el flujo completo sin cuentas externas. Para que Issues, Sheet, Turnstile de producción, Resend, PageSpeed y Have I Been Pwned dejen el modo simulado, el Worker de licencias debe recibir:

  • GITHUB_TOKEN y GITHUB_REPO
  • SHEETS_WEBHOOK
  • TURNSTILE_SECRET
  • RESEND_KEY, MAIL_FROM, MAIL_TO
  • en integración continua, PSI_API_KEY y HIBP_API_KEY

Hasta entonces, el inbox local es la fuente de verdad del laboratorio.
