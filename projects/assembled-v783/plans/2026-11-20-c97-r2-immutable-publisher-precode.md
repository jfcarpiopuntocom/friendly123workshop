**ROOT:** Gate D7 `frozen-r2-packager.mjs` produces archive.objects=[manifest,...pages]. C95 returns two archives without writer. `frozen-r2-source.mjs` rejects incomplete pages, but an uncontrolled PUT can leave a visible partial manifest and overwrite a prior HEAD, despite pin protection.

**RED contract (real Miniflare R2 + Workerd):** missing write-once transactional publication interface; verify (1) write pages before any manifest; (2) immutable conditional `put(key,body,{onlyIf:new Headers({'if-none-match':'*'})})` with SHA256 readback, identical retry allowed; (3) conflicting reattempt refuses and retains original bytes; (4) fail injection on page 2 yields zero manifests, then retry succeeds; (5) independently pinned Workerd frozen source reads -ops/-cat and import matches business facts; (6) two archives are required, no false readiness without both manifests and readback.

**GREEN:** Accept only prepacked C95 sealed artifacts with verified room/head/manifest hashes and exactly enumerated keys. Validate both before any write. R2 page-first write-only-if-absent; hash readback exact; manifest-last; return exact pins ONLY after both manifests read back. Never delete/overwrite or issue a production certificate, no live service access; intended to be invoked only by separately authenticated server owner/canary.
